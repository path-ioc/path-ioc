# 赞助与支持 Path-IoC

Path-IoC 是一套遵循 MIT 开源协议的纯同步拓扑依赖查找引擎（IoC-DL）与通用模块化基础库，如同 Lodash 一般纯粹通用，零外部依赖，专为现代高性能 TypeScript 应用量身打造。

您的赞助将直接投入于：
- **内核极致性能与前沿研发**：持续的 Kahn 图论拓扑调度优化、硬件压测基准、零锁无反射机制与微秒级装配调优；
- **全生态打包工具原生适配**：持续维护针对 Vite、Rolldown、Webpack 5、Rspack 与 Rollup 的一流官方插件；
- **高质量架构思想与双语文档**：深度专栏文章、系统架构设计与中英文技术资源的持续输出；
- **独立长效维护保障**：保持纯粹的工程师驱动与中立性，免受任何商业巨头封闭协议绑架。
